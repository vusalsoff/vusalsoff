## ⚡ Kodların arxasındakı mühəndis

Mən **Vüsal Süleymanov**, **Azərbaycan Dövlət Aqrar Universitetində (ADAU) Kompüter Mühəndisliyi** ixtisası üzrə təhsil alan proqram mühəndisi və texnologiya təşəbbüskarıyam.

Fəaliyyətim **full-stack mühəndislik, süni intellekt, robototexnika və aqrotexnologiya startaplarının** kəsişməsində cəmləşib. İdeyanı sadəcə konsept olaraq saxlamayıb, etibarlı arxitektura, optimallaşdırılmış kod və yüksək istifadəçi təcrübəsinə malik real məhsula çevirməyi hədəfləyirəm.

> **Əsas prinsipim:** *İnnovasiya haqqında sadəcə danışma — onu layihələndir, qur və faydalı nəticə hasil et.*

<tr>
<td width="50%" valign="top">

### 🧠 Əsas bacarıqlar və sahələr
* **Full-Stack Sistemlər:** Yüksək yüklü veb tətbiqləri, etibarlı RESTful mikroservislər
* **Süni İntellekt və CV:** AI agent strukturları, axtarış sistemləri və tətbiqi kompüter görməsi
* **Aparat Təminatı və IoT:** Robototexnika, sensor telemetriyası və mikrokontrollerlər (ESP32 / Arduino)
* **Məhsul İnkişafı:** Çevik MVP prototipləşdirməsi, miqyaslanma və məhsul arxitekturası
* **Mühəndislik Standartları:** Təmiz kod, xətaların dərindən analizi və performans optimallaşdırması

* **Real Mühit Kompüter Görməsi:** Aqrar və avtonom qurğular üçün vizual obyekt tanıma
* **Mobil Tətbiqlər:** React Native əsaslı çarpaz platformalı mobil ekosistemlər
* **Müəssisə Səviyyəli Backend:** .NET Core və Spring Boot ilə paylanmış sistemlər
